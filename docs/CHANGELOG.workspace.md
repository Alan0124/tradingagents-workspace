# 工作台更新记录

## 1.1 · 2026-10-20

- 调整桌面与移动端视觉：深森林绿侧栏、暖白画布、衬线标题、更清晰的表单和报告阅读层级。
- 加入明确的历史配置复用入口、报告标签键盘导航、页面状态恢复和请求竞争保护。
- 改进断线重试、运行记录滚动与键盘焦点保留。
- 加强服务启动与任务互斥、进程管理、配置校验与凭据隔离。
- 让工作台进入 Python 包分发，增加 `tradingagents-web` 命令与浏览器静态资源。
- 改进 macOS 桌面入口生成，支持路径包含空格，并使用生成时的 Python 环境。
- 补充中文 README、上游文档、使用手册、截图和自动检查。
- 修复上游锁工具在 macOS 上缺少 `EDEADLOCK` 别名时的兼容问题。

## 1.0 · 2026-10-20

- 在原版 TradingAgents 0.7.0 引擎上新增本地浏览器界面。
- 支持模型配置、任务发起与停止、阶段进展、分章节报告、历史存储和 HTML / Markdown 导出。
- 提供 macOS 桌面启动器。

本记录描述浏览器工作台扩展；原引擎更新见根目录 [CHANGELOG.md](../CHANGELOG.md)。
