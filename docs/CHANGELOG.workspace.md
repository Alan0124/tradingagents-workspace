# 工作台更新记录

## 2.1 · 2026-10-21

- A 股市场情绪使用东方财富中文资讯和社区样本，不再查询 StockTwits 与英文 Reddit 社区；新闻分析师默认同步使用中文个股资讯。
- 展示程序核验的样本数量与实际日期范围，区分新闻转载、自媒体与股民观点，保留原始链接。
- 完全没有有效情绪数据时直接返回简短的资料不足说明，不调用模型、不生成中性 5/10 占位分。
- 缺失目标价时省略该字段；修复人民币、港元等明确单一价格的解析，拒绝把区间或多个数字拼成目标价。
- 历史最终决策在阅读和导出时隐藏缺失目标价占位，原始研究记录保留。

## 2.0 · 2026-10-20

- 将暖白 / 森林绿风格替换为暖石墨灰与克制香槟色，保留上一版衬线标题与字体组合，调整阅读字号、留白和响应式布局。
- 移除资产类型筛选，输入标的后自动识别；加密资产自动调整公司基本面维度。
- 将模型输入改成明确的下拉选项，支持订阅模型刷新及显式自定义模式。
- 为原先只作装饰的研究设置图标补上实际设置入口，检查交互和错误反馈。
- 加入历史价格轨迹、报告覆盖和实际 Token 用量可视化，将报告阅读置于次要图表之前。
- 补齐 CFD 别名兼容、Windows 子进程中文编码与行情接口测试。

## 1.1 · 2026-10-20

- 调整桌面与移动端视觉：深森林绿侧栏、暖白画布、衬线标题、更清晰的表单和报告阅读层级。
- 加入明确的历史配置复用入口、报告标签键盘导航、页面状态恢复和请求竞争保护。
- 改进断线重试、运行记录滚动与键盘焦点保留。
- 加强服务启动与任务互斥、进程管理、配置校验与凭据隔离。
- 让工作台进入 Python 包分发，增加 `tradingagents-web` 命令与浏览器静态资源。
- 改进 macOS 桌面入口生成，支持路径包含空格，并使用生成时的 Python 环境。
- 补充中文 README、上游文档、使用手册、截图和自动检查。
- 修复上游锁工具在 macOS 上缺少 `EDEADLOCK` 别名时的兼容问题。
