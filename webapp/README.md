# 本地投研工作台使用说明

基于 TradingAgents 的浏览器界面，保留原项目的分析流程。安装方式与项目介绍见 [仓库首页](../README.md)。

## 启动

在项目目录激活虚拟环境后：

```sh
tradingagents-web --open
# 等价方式
python -m webapp.server --open
```

服务默认使用 `http://127.0.0.1:18765`。如果端口占用，会在 18765–18784 范围内查找可用地址；重复启动会复用已经运行的工作台。

macOS 用户可执行一次 `python -m webapp.install_desktop`，在桌面生成 **TradingAgents 投研台.app**。应用绑定生成时的 Python 环境与项目位置，移动项目后应重新生成。

## 配置模型

1. 点击「模型设置」或表单中的「配置」。
2. 选择服务商；使用 API 的服务需输入该服务对应的 API Key。
3. 从下拉列表选择快速模型与深度模型。ChatGPT 订阅可点击「刷新可用模型」获取账号可见的选项；自定义模型需先选择「自定义」，再填写 ID。候选列表不等于账号已获对应权限。
4. 自定义兼容接口必须填写完整的 HTTP(S) 地址。接口地址不接受内嵌凭据、查询参数或 URL fragment。
5. 保存。留空 API Key 表示保留已保存的密钥，不会清除密钥。

快速模型承担分析、研究辩论、交易员和风险讨论，深度模型承担研究经理与组合经理。Ollama 需要先自行启动本地服务、拉取对应模型。

「已配置」只表示必填配置齐全，不是连通性验证。工作台不会在保存时调用付费模型。

ChatGPT 订阅选项沿用原项目登录实现。点击「登录 ChatGPT」后，在新窗口内完成授权；弹窗被拦截时可点击页面中的登录链接。登录能否成功取决于服务、账号和实际授权结果。

## 发起与阅读研究

- **标的：**支持 `AAPL`、`0700.HK`、`600519.SS`、`BTC-USD` 等代码；`600519`、`SH600519`、`600519.SH` 等 A 股写法会统一成同一个标的，数据源不会各自识别成不同代码。
- **日期：**不能晚于今天。选择历史日期不等于模型完全不具备此日期之后的知识。
- **类型：**由代码自动识别，无需筛选。公司基本面不适用于加密资产，相应分析维度会自动调整。
- **维度：**至少选择一位适用于该标的的分析师。
- **深度：**1–3 轮研究及风险讨论，更多轮次通常意味着更多耗时与调用。

点击「开始研究」后，任务在独立后台进程运行。研究进程显示各阶段；展开运行记录可查看工具调用和阶段事件。报告完成一部分后，就会在章节标签里显示。

报告目录支持方向键、Home、End 导航；最终决策有独立的快捷入口。配置与流程可以收起，结论、证据质量与行情在详细章节之前。输入/输出 Token 数量仅在模型服务提供用量时累计，不能直接等同于费用；明确报告的零与缺少用量分开显示。

A 股情绪分析自动使用东方财富公开中文资讯与社区样本，并展示样本数量、实际日期范围和原始链接。新闻转载、自媒体和股民观点分别标注；同一平台的观点不视为独立来源共识。采样只覆盖当前返回的有限页面，不能保证完整一周或历史窗口。完全没有有效条目时显示「资料不足」，不打中性占位分，也不为此调用模型。

同一天的条目按完整发布时间排序，保留实际来源类别；1–2 条实质样本标记为覆盖有限，单一平台的情绪置信度由程序限制为最多中等。样本数量不等于代表性，媒体观点不能代称全体股民。

A 股当前日期的基本面工具接入东方财富原生财报，显示报告期、公告日期和人民币单位。利润及现金流标明累计口径，不能直接当作单季数据。供应商当前数据库可能含追溯重述；历史分析仍不将其冒充原始披露版本，没有可核实的历史财报时明确标记资料不足。

最终报告只在有明确单一目标价时显示「Price Target」。缺失、区间或含糊表述会省略该项；旧报告里的缺失占位也会在阅读、导出时隐藏，不改变原始存档。新的中文来源和情绪判断需要重新运行研究后生效。

## 研究观测

- **价格轨迹：**获取截至分析日的历史收盘价。图表、数据工具和技术指标统一采用 Yahoo `Close`，关闭额外股息调整，并隔离旧口径缓存。Yahoo 本身仍可能回溯调整拆股历史，因此该序列不等于逐笔原始报价，也不保证严格点时回测。数据不可用时显示明确提示，不用模拟行情填充。
- **研究覆盖：**分别展示章节生成状态和采集证据状态。「已获取数据」只表示工具返回了数据，不保证完整性、代表性或结论正确；「覆盖有限」「资料不足」「未验证」分别保留。旧报告没有采集凭证时不自动升级为已验证。
- **模型用量：**展示服务商实际返回的输入与输出 Token。未返回用量时显示暂无数据，不推测费用。

新的研究会保存原始工具返回快照、来源、查询日期、抓取时间与 SHA-256，报告中的 `E-` 编号对应这些凭证。相同数据请求在一次研究内共用抓取结果；重复编号、URL 或平台不能当作多份独立证据。证据 JSON 可以单独下载，供事后核对；这是一份采集记录，不是模型每条结论已经核验的证明。超过归档长度上限时会明确标记截断。所有所选维度均未获得有效数据时，最终结论由程序标记为 `REVIEW`，不提供方向性评级或目标价。

## 历史与复用

「研究档案」保存每一次任务的配置、状态和报告。可以按标的代码或模型服务搜索。

查看过去的报告时，你当前的模型配置不会被悄悄替换。需要重复该次研究时，点击报告旁的 **复用配置**，确认表单后再开始。历史配置中的模型或接口可能已经失效。

刷新页面会恢复正在运行的任务，或当前标签最近查看的研究。关闭浏览器不会停止任务。需要停止时点击「停止研究」，已收到的报告和证据会保留。

新任务的断点文件与证据保存在各自任务目录。中断后可在原任务上点击「继续研究」，按原配置从可用断点继续；不会隐式借用其他任务或不同配置的断点。旧任务没有断点时需要重新研究。模型请求中途失败可能仍产生服务商费用，断点续跑不保证每个中断请求都能免于重试。

后台设有总运行时限、调用次数和 Token 预算，超过上限会终止任务并保留部分结果。Token 预算依赖服务商返回的用量，不是精确费用硬限额；已在途的并行请求可能超过预算。认证、限流、超时等错误不会再因为结构化输出回退而额外调用一次模型。

## 导出

- **MD ↓：**下载 Markdown，便于编辑和继续整理。
- **导出报告：**下载独立 HTML 页面，可离线阅读或通过浏览器打印为 PDF。
- **证据 JSON：**下载本次研究实际采集到的工具快照；旧记录没有凭证时不显示此入口。

导出未完成的研究时，只会包含已经收到的章节；状态与评级会随报告一并写入。

## 数据保存位置

源码安装时：

| 内容 | 位置 |
| --- | --- |
| API Key | 项目根目录 `.env`，仅本机当前用户可读写 |
| 偏好与 SQLite 历史记录 | `.local/web/` |
| 每次分析的报告、证据与独立缓存/断点 | `.local/web/runs/<任务 ID>/` |
| 记忆 | 沿用原配置，默认 `~/.tradingagents/` |
| 桌面启动日志 | `.local/web/server.log` |

安装 wheel 时，工作台默认将配置与历史写入 `~/.tradingagents/workspace/`；也可通过 `TRADINGAGENTS_WORKSPACE_DIR` 指定工作空间。

请勿上传 `.env`、`.local/`、缓存、登录文件或私人报告。仅本地运行界面；执行分析时仍会访问模型服务与金融数据源。

## 常见问题

**保存配置后仍不能运行？**
检查模型 ID、账号权限、密钥、接口地址与网络。已配置状态不代表连通性已验证。

**数据工具提示没有数据或限流？**
数据源覆盖因市场而异。可先减少分析维度，确认标的与日期有效，再检查原项目支持的数据服务与相应凭据。

**模型调用统计有数值，Token 为零？**
部分服务不返回统一格式的 Token 使用量。

**页面提示连接中断？**
服务可能被关闭或电脑休眠。重新打开桌面应用或执行启动命令，之后刷新页面。不要直接删除历史数据库。

## 开发检查

```sh
python -m unittest discover -s webapp/tests -v
node --check webapp/static/app.js
node --check webapp/static/visuals.js
node --test webapp/tests/frontend*.test.*
```

`webapp.tests.browser_fixture` 是临时离线浏览器测试服务器，使用模拟模型运行真实 LangGraph 流程，数据与日常研究记录隔离。它不是投资分析示例，也不由桌面入口加载。
